# zahid-portfolio

Personal portfolio website for Zahid Ali — Full Stack Software Engineer.

## Tech Stack

- **React** + **TypeScript** with Vite
- **Tailwind CSS** for styling
- **Framer Motion** for animations
- **Markdown blog** with static content

## Getting Started

```sh
npm install
npm run dev
```

## Features

- Responsive single-page portfolio with experience, projects, skills, and contact sections
- Markdown-powered blog with syntax highlighting
- hCaptcha-protected contact form via Web3Forms
- Dark theme with monospace design language
